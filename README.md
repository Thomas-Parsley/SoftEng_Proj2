# SoftEng_Proj2
Software Engineering Fall 2025 Project 2 Group 2

## Summary
This system is used to recognize classes of things, which include:
Humans
Dogs
Cats
Lightsabers (Star Wars)
Sith Lighsabers (Star Wars)
Daleks (Doctor Who)
This can be applied to photos, videos, and live using a camera on a ready device.
The current and most accurate mode is the dect_model_test_results22.

## Installation
To get the system running, the below libraries should be downloaded within the python environment.
For video usage, RunModel.py in the video_tests folder should be downloaded, along with the current and accurate model.  For live detection, RunLiveDetect.py should be downloaded, along with the current model.

## Usage Procedures
To use the either detection, either detection should be run within the same directory as the model.  For the video usage, the input video name should be edited in, along with the directory path for the model.  The desired output file path should also be edited.  For live usage, a usable webcam should be owned.  This should allow the live detection to operate.

## Library Dependencies
The libraries required and used for this project ultralytics and opencv (cv2).
